# DOTAANALYSIS

DOTAANALYSIS is a continuing game-design research project focused on extracting reusable design insight from Dota 2.

The project studies three broad areas:

- hero design;
- item design;
- underlying system, numerical, and environmental design.

The goal is not to produce strategy guides or a static encyclopedia. The repository records the project's current best understanding of how Dota 2 creates decisions, trade-offs, counterplay, asymmetry, feel, pacing, and systemic depth.

Research happens through sequential ChatGPT sessions. GitHub is the durable checkpoint that allows a fresh session to resume the same research thread when a previous session reaches its context limit.
